# Social Network Friend Recommendation System

This project implements a simple social network recommendation system using Python.

The system suggests potential friends based on mutual connections using a friend-of-friend algorithm similar to social media platforms.

## Technologies Used
- Python
- JSON
- Jupyter Notebook
- Data Structures (Dictionary, Set)

## Features
- Analyze social network relationships
- Identify mutual friends
- Generate friend recommendations
- Rank users based on shared connections
